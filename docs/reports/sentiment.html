Recommendation: qwen-small

qwen-small has the highest score and no cheaper candidate is confirmed within 0.05 of it.

Rule: the cheapest candidate whose score is confirmed (95% confidence, Holm-adjusted) to be no more than 0.05 below the best. "Not significantly different" is never treated as "tied". For classification the tie test is conservative when the models rarely disagree (a discordance guard), so it can ask for more examples rather than declare a tie.
